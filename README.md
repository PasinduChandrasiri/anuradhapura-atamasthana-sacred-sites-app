# ☸️ අටමස්ථාන වන්දනාව | Atamasthana Wandana Flutter App

A modern Flutter mobile application showcasing the sacred 8 ancient sites ([translate:අටමස්ථාන]) of Anuradhapura, Sri Lanka—featuring an elegant glassmorphic user interface, interactive sliding galleries, and Sinhala-language content.

---

## 📱 Project Overview

Designed and developed an immersive app for exploring the Anuradhapura [translate:අටමස්ථාන], each with visual storytelling, tab navigation, and responsive UI in a clean black & white theme.

---

## ✨ Key Highlights

- **Glassmorphic Dropdown Menu:**  
  Beautifully blurred, frosted-glass effect popup for intuitive navigation.

- **Interactive Sliding Image Galleries:**  
  Carousel of high-quality images for each of the 8 sacred sites with smooth, autoplay sliding.

- **Detailed Descriptions & Wikipedia Integration:**  
  Sinhala-language descriptions and direct Wikipedia links for deeper cultural knowledge.

- **Seamless Social & Contact Access:**  
  Quick access via an elegant glassmorphic menu to Contact and About sections.

- **Responsive Tab Navigation:**  
  Effortlessly explore all sacred locations using Flutter’s TabBar and TabBarView components.

- **Consistent Theming:**  
  Minimalistic black-and-white visuals with rounded corners and sleek button designs.

## 🚀 Getting Started

1. **Clone the repository:**
git clone https://github.com/PasinduChandrasiri/atamasthana_wandana.git

2. **Install dependencies:**
flutter pub get

3. **Run the app:**
flutter run

4. **Build for release:**
flutter build apk --release
